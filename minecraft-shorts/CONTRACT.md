# Village shorts — build contract

Goal: two ~12 s vertical shorts (Instagram Reels) in a blocky voxel-game village style, rendered with
Blender 5.3 Cycles on CPU, with word-by-word pixel captions. Everything is generated by Python scripts
from scratch (no hand-made .blend files), so builds are reproducible.

## Hard rules

- **Original art only.** Every texture, model and font glyph is generated in code in this repo. Do not
  download, extract or copy game assets, skins, fonts, logos or resource packs. The look is "blocky
  voxel village", with our own pixel art.
- Blender is the pip module `bpy` 5.3.0. Run scripts from the project root as modules:
  `cd /home/user/Project-2-/minecraft-shorts && $BPY -m engine.blocks`
  where `BPY=/tmp/claude-0/-home-user-Project-2-/be90bb9d-3fc7-572c-941a-ff79c8b6ef48/scratchpad/bl/bin/python`.
  (numpy and pillow are installed in that environment. There is no `blender` binary and no GPU.)
- Blender 5.x changed parts of the Python API. When a call fails, introspect (`dir()`, `bl_rna.properties`)
  instead of guessing. Known: compositor tree is `scene.compositing_node_group` (not `scene.node_tree`);
  `use_nodes` is deprecated but harmless; Principled inputs are `Specular IOR Level`, `Emission Color`,
  `Emission Strength`. EEVEE is NOT available here (no EGL) — Cycles CPU only.
- Prefer the data API (`bpy.data.*`, `bmesh`, `obj.keyframe_insert`) over `bpy.ops.*` (ops are fragile headless).
- The machine has 4 CPU cores shared by several agents. Test stills: 540x960, <=16 samples, 2 threads
  (`engine/quick.py` does this). Wrap every render command in `timeout 300`. Never launch a long render.
- **Look at what you render.** After each test render, open the PNG with the Read tool and judge it as a
  picture. Iterate until it looks good, not until it merely runs.
- Only edit the files you own (listed per role). `engine/pix.py` and `engine/quick.py` are finished and shared.

## Conventions

- Z is up. 1 block = 1 Blender unit. 1 texture pixel = 1/16 unit. Block (x, y, z) occupies
  [x, x+1] x [y, y+1] x [z, z+1]. Ground surface is at z = 0 in the village square (top of the blocks at z = -1).
- 24 fps. Final frames render at 720x1280 and are upscaled to 1080x1920 in post; captions are drawn at 1080x1920.
- Characters stand with feet at their root empty, facing **-Y** at yaw 0. Yaw is rotation about Z in radians.
- Textures are 16x16 pixel art with Closest filtering (`pix.pixel_material`). Seed every random generator.
- Every public function has a one-line docstring. Every engine module has an `if __name__ == "__main__":`
  self-test that renders stills to `out/test/<module>_*.png` using `engine/quick.py`.
- Performance budget for a final frame: <= ~15 s at 720x1280, 24 samples, 4 threads. Keep the whole set
  under ~200k faces; cull hidden block faces; use point/spot lights (not only emissive meshes) for lanterns.

## Art direction (see the three reference screenshots given in your brief)

- Cinematic, not gameplay: low camera, long lens, strong shallow depth of field, motion blur, slow moves.
- Late-afternoon gold, dusk orange-to-purple, and moonlit night with warm lanterns that bloom.
- Sky: vertical colour gradient, square sun or square moon with a soft glow, small square stars at night,
  flat blocky clouds.
- Village materials: oak planks and logs, cobblestone and mossy cobblestone, dirt paths, grass with tufts
  and flowers, glass panes, hanging lanterns, beds with coloured blanket and white pillow.
- Villagers: tall head, big nose, single brow, arms folded into the sleeves of a long robe. The profession
  shows in the robe/hat. The "nitwit" wears a plain green robe. The player is an ordinary blocky human with
  our own skin: brown hair, red hooded top, dark grey trousers.

Required set pieces (one continuous village, roughly 56 x 56 blocks, on gently uneven grass):
1. **Square**: dirt-path plaza about 9x9 with the bell hanging from a frame in the middle. Anchors
   `bell`, `bell_ringer` (where the player stands to ring it), `square_n/e/s/w`.
2. **Five or six houses** around the square, different sizes, oak/cobble with stair or stepped roofs,
   working doors (`doors["house_a"]` ...), glass windows, a bed and a lantern inside. `house_a` must be
   roomy enough to film inside (at least 5x6 interior, 3 high) with three beds; anchors
   `house_a_door_out`, `house_a_door_in`, `house_a_inside_1..3`, `house_a_bed_1..3`,
   `house_a_cam` (a corner a camera can sit in looking at the door). Paths `square_to_house_a`,
   `square_to_house_b`, `square_to_house_c` (door-to-door running routes from the square).
3. **Workstations**: a small fenced wheat farm with water and a composter (`farm_work`), an open-sided
   library corner with bookshelves and a lectern (`library_work`), a smithy shelter with blast furnace
   and smithing table (`smithy_work`). Each anchor is where a villager stands facing the station; also
   `<name>_station` for the station itself.
4. **Trading hall**: a long building or roofed row with six 1x1 cells side by side, each closed in
   front by a glass pane on the upper block and a trapdoor/slab on the lower, a workstation in front of
   each cell, and a lantern-lit aisle a camera can dolly along. Anchors `cell_1..6` (stand spot inside),
   `hall_aisle_start`, `hall_aisle_end`.
5. **Lantern posts** along the paths (fence post + hanging lantern), plus lanterns under eaves.
6. **Way out**: a path `exit_road` leading from the square past the last house into an open meadow with
   tall grass, poppies and a few oak trees, rising slightly so the horizon is clean. Anchors
   `exit_gate` (edge of the village), `meadow_far`, `nitwit_idle` (a lonely spot at the village edge
   with the houses behind it).

```python
    def look_at(self, frame, target, ease=6): ...                # turn head (clamped) toward a world point
    def face(self, frame, target, ease=8): ...                   # turn whole body toward a world point
    def idle(self, frame_start, frame_end, seed=0): ...          # small head turns, weight shifts
    def nod(self, frame); def shake(self, frame); def flinch(self, frame): ...
    def swing_arm(self, frame): ...                              # player: right-arm use swing; villager: small jolt
    def hold(self, obj | None): ...                              # player: item in right hand
    def lie_down(self, frame, bed_pos, yaw): ...                 # sleeping pose on a bed
    def show(self, frame, visible=True): ...                     # keyed render visibility
```
Villager run = panicked fast shuffle (legs fast, body leaning forward, head bobbing), arms stay folded.
All animation is plain object keyframes on a parented box rig (no armatures needed). Motion must loop
cleanly and read well with motion blur.
